# LVGL 表情移植与状态同步

## 数据如何到达屏幕

浏览器负责交互和状态选择。每个显示帧结束后，它把当前表情、字幕和动画参数交给 `DeviceMonitor`；模块限制为一个请求在途，状态变化时最快 25 Hz，稳定时约 4 Hz 校时。传输的是 JSON，不包含 Canvas 像素或绘图命令。

`POST /api/face` 校验 JSON 并保存 `FaceUpdate`。显示任务读取快照，用板端经过的时间补足 `time`、`age`、进度和时钟，再使用 LVGL Canvas/ThorVG 绘制原页面的几何图形，合成为 ARGB8888，最后一次性转成大端 RGB565，经 Waveshare 驱动写 GC9A01。网页关闭后最后状态的动画仍由 MCU 推进。

聊天传递昵称、已排版的文字行、分页和出现时间；火柴人传递动作名称，摄像头模式传递 13 个关节与眼睛/嘴巴类型。它们仍是语义信息，没有把截图压缩后伪装成“状态”。字幕的缩放、淡入、字号收缩，爱心、月亮、彩纸、进度环等均在板端实现。

## 状态协议 v2

请求小于 4096 字节，UTF-8，非法枚举、超长字符串、越界数值、畸形 JSON 返回 400。

```json
{
  "protocol": 2,
  "seq": 123,
  "face": "pressed",
  "text": "",
  "time": 12.34,
  "age": 0.8,
  "blink": false,
  "blinkRemaining": 0,
  "hold": true,
  "holdProgress": 0.45,
  "holdRate": 0.625,
  "wallClockMs": 1793530000000,
  "utcOffsetMinutes": 480
}
```

- `time` 是页面全局动画时钟；`age` 是当前动作年龄，单位秒。板子从接收时刻起继续计时。
- `blinkRemaining` 限定闭眼剩余时间，避免把一个重复的 true 锁存成反复眨眼。
- `holdRate` 是每秒进度变化量。长按为正、等待回复倒计时为负；板端夹在 0～1。
- `wallClockMs` 加时区偏移用于时钟和消息时间，不依赖 MCU 上电时刻。
- `chat` 为 `{name,pages:[[行…]],starts:[秒…]}`，最多 4 页、每页 3 行；前端当前最多 60 字的输入适用。
- `stick` 为 `{anim,camera,joints,eyes,mouth}`；`joints` 顺序为 head、neck、sL、sR、hip、eL、eR、hL、hR、kL、kR、fL、fR。
- `paused:true` 固定动画时刻，供确定性画面对照；正常交互不发送它。

响应区分 `client_seq`（服务器已接收）和 `displayed_seq`（已经绘制并发往 LCD）。HTTP 成功本身不等于屏幕已显示。

`GET /api/state` 返回实际耗时、内存、IMU 和 `local` 本地事件。网页收到新的本地 dizzy 事件后按剩余时间显示相同表情，不会不断把板端晃动效果覆盖成 idle。

## 固定地址、开机和晃动

浏览器访问 **http://192.168.137.73/**。此地址适用于当前 Windows 热点 192.168.137.0/24；电脑必须开启移动热点。热点关闭时即使串口刚输出过地址，电脑也无法访问。串口同时输出 Wi-Fi MAC、网关和掩码，便于区分网络与显示问题。

上电立即绘制默认 idle，外环在未联网时以 3 秒周期红色呼吸，连接热点后恢复页面 idle 的青色。屏幕不显示 IMU 数据；IMU 数据保留在后台与设备状态面板。

检测晃动使用相邻加速度向量之差，不把静态重力当作晃动：450 ms 内两次超过 7.5 m/s² 的变化触发 dizzy，固定播放 3000 ms，触发间隔至少 3800 ms。阈值集中在 `display_task.cpp`。普通缓慢转动不会直接触发；播放结束后恢复最新网页状态。

## 已修正的问题

1. 旧版本的聊天和火柴人使用近似图案，且缺少分页/姿态状态。现在逐项移植原公式，聊天直接使用网页排版结果。
2. 音符和对勾在原中文字体中没有对应字形。生成脚本把 Segoe UI Symbol 的对应轮廓补进共用字体，浏览器和 LVGL 都能显示。
3. “网络断了”表情的 90° 圆弧触发 LVGL 9.4 `append_arc` 的浮点退化末段：可能出现 0/0 控制点，使软件绘制卡住。适配层改成等分圆弧，每段使用 `4/3*tan(角度/4)` 生成三次贝塞尔控制点，避免近零末段。该表情只改变图案，不调用断网操作。
4. LVGL 9.4 的矢量 alpha 乘法把 255×255 截断为 254，使不透明色变暗一级，落在 RGB565 边界时尤其明显。构建脚本对固定版本的该处改用除以 255 的舍入算法，依赖重装后仍会自动应用。
5. 原转换每像素做浮点圆形判断并逐字节写 PSRAM，实测约 50 ms。现在每行只计算裁剪范围，整 16 位写 RGB565，初测约 20 ms。
6. Canvas 的 middle 文字基线不同于 LVGL 行框中心，原适配会让时钟数字偏低。现按共用字体在 Chrome 中的实测基线校正；通过固定版本 tiny_ttf 的小型度量桥接保留浮点字宽，逐字定位，避免英文逐字取整产生累积间距误差。更换字体或 LVGL 版本后必须重新对照。

## 验证与显示一致性的边界

自动对照使用真实 HTTP 状态接口写入固定时刻，再读取 `GET /api/screen.rgb565`；后者只读取板端图像用于测试，不参与正常同步。`X-Frame-Seq` 必须和测试状态一致，防止把其他标签页刚切换的表情误认为当前参考图。

```powershell
pio run
pio run -t upload --upload-port COM10
python scripts/serial_capture.py --port COM10 --seconds 25
node scripts/verify_face_sync.mjs http://192.168.137.73
python scripts/compare_face_frames.py
```

对照覆盖所有表情、字幕入场、眨眼、进度 0/25/50/100%、一天内不同时段、聊天分页以及所有 13 个火柴人动作。输出保存在 `.pio/face_qa/`；旧 `.pio/sync_test/` 是早期 mock 测试，不能证明实物结果。

目标调度间隔 33 ms，**不等于实测 30 fps**。实际帧率由矢量绘制、字体、PSRAM 转换、SPI 和任务调度共同决定，网页设备面板显示当前实测值。SPI 整帧初测约 20 ms。

移植保留动画公式、图形布局、配色和交互状态。浏览器 Canvas 的光栅器与 LVGL/ThorVG、TrueType 字形栅格化和整数文字定位存在差异，因此不能把“公式一致”说成每个像素完全相同。误差脚本会保留真实差异，不能通过放宽阈值或替换原动画来掩盖。

### 2026-11-01 实物验证记录

- 最终固件通过 PlatformIO 编译，并已烧录 COM10；写入 3,992,256 字节，烧录校验通过。页面、监控模块和时钟字体从真实板端下载后与本地源文件一致。
- 73 组固定状态全部在真实板端完成绘制和诊断帧读取，截图序号逐组匹配，包括“网络断了”、两种音符、字幕、进度、时钟、聊天与全部火柴人动作。没有复现绘制卡死或栈溢出。
- 14 项实际 HTTP 协议检查通过，覆盖合法请求、畸形 JSON、尾随数据、类型/范围错误、超长 UTF-8、聊天结构、异常浮点数、摄像头关节和超大请求。
- 圆形有效区域内，73 组对照的 RGB 通道平均绝对误差中位数为 **0.730/255**，最大值 **5.235/255**（夜间时钟）；这些是整幅区域的统计，不能说明文字边缘逐像素一致。浏览器和 LVGL 字形、抗锯齿仍有可见差异。原始帧、参考 PNG、差异图和 `comparison.json` 保留在 `.pio/face_qa/`。
- 单帧本地绘制耗时 74.3～161.3 ms，中位数 88.3 ms；SPI 整帧发送中位数 20.1 ms。按每次至少 5 ms 让出任务估算，连续变化画面约 **5～10 fps**，中位帧耗时对应约 8.8 fps；这不是独立高速摄影测得的屏幕刷新率，也没有达到 30 fps。静态 idle 会跳过重复绘制。
- 回归期间空闲内部堆最低约 104 KiB；显示任务最小剩余栈 21,024 字节。随后用户实际操作时仍能正常读取 HTTP 状态和变化的 IMU 数据，字体缓存扩展后内部堆约 64 KiB。
- 用户实物确认：晃动后正常出现“转晕了”，约 3 秒恢复。随后 `/api/state` 显示本地事件计数为 1、剩余时间为 0；此次人工动作未采集到完整的逐毫秒事件轨迹，不将它描述为自动计时精度测试。
- 固定地址 **http://192.168.137.73/** 已恢复访问。此前 Windows 热点关闭时，192.168.137.1 网卡地址和热点路由消失；用户重新开启热点后网络恢复。固定 IP 不代替开启热点。

本轮验证后已允许重新打开正常网页，固件不处于测试暂停模式。未联网红色呼吸与联网恢复使用板端实际 Wi-Fi 状态，不依赖网页在线；本轮没有再次要求用户关闭热点做视觉验收。
